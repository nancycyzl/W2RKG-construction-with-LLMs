This folder contains all the integrated KG data, obtained with fusion_triples.py.
Each subfolder correponds to the resulting KG with a different distance threshold (in the filename, the 06/07/08/09 refer to distance threshold of 0.4, 0.3, 0.2, 0.1, correspondly).
The final KG data are stored in fused_triples_aggregated.json file within each subfolder, while all other files are intermediate files.
